# beginner_level-
A collection of Python practice programs covering variables, data types, numbers, functions, lists, conditionals, dictionaries, tuples, and real-world problem-solving. Includes BMI calculation, city-country mapping, list manipulation, expense tracking, and fundamental Python programming concepts.

# 🐍 Python Basics & Practice

Welcome to my Python Basics repository! 

This repository contains beginner-level Python programs and practice tasks that I completed while learning the fundamentals of Python programming. The tasks focus on variables, numbers, lists, conditional statements, dictionaries, and basic problem-solving.

## 📚 Topics Covered

### 1. Variables
Basic practice with variables and data types.

- Creating and assigning variables
- Checking data types
- Understanding Python keywords
- Calculating Simple Interest using variables

### 2. Numbers
Practice with numbers, arithmetic operations, functions, and formatting.

- Using the `format()` function
- Working with numbers and characters
- Calculating the area of a circle
- Calculating the amount of water in a circular pond
- Calculating speed using distance and time
- Formatting numerical output

### 3. Lists
Practice with Python lists and list manipulation using a Justice League example.

- Creating lists
- Finding the number of elements
- Adding new elements
- Moving elements within a list
- Replacing list elements
- Sorting lists alphabetically
- Accessing elements using indexes

### 4. If Conditions
Practice with decision-making using `if`, `elif`, and `else`.

- BMI calculator
- BMI category determination
- Finding the country of a given city
- Comparing two cities
- Checking whether two cities belong to the same country

### 5. Dictionaries
Practice with dictionaries and tuples using practical examples.

- Creating lists of names
- Creating tuples containing names and their lengths
- Creating expense dictionaries
- Calculating total expenses
- Comparing expenses
- Finding differences between expense categories
